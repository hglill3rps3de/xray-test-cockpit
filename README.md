# xray-test-cockpit
Prototyp

## Zusammenarbeit

- `main` ist immer deploybar/stabil — niemand pusht direkt dorthin.
- Für jede Änderung einen eigenen Branch anlegen: `git checkout -b <kurzname>/<thema>` (z.B. `hg/login-page`).
- Änderungen committen und pushen: `git push -u origin <branchname>`.
- Pull Request gegen `main` öffnen, mindestens eine Person lässt review.
- Nach dem Merge den eigenen Branch löschen und lokal `git pull` auf `main` machen.
